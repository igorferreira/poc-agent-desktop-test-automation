# C4 — Consultar clientes

Antes, leia `cases/AGENT.md`. Ele diz como ler a tela, como digitar e como gravar o resultado.

## Objetivo

Consultar um cliente que existe e um que não existe. Relatar os dados do primeiro e a mensagem do segundo.

## Pré-condição

- O operador preparou o ambiente e passou o `run_id`.
- O app está no menu principal: o identificador no canto direito da linha 1 é `T01`.
- Confira isso com uma leitura antes de qualquer outra coisa. Se não for `T01`, pare e avise o operador.

## O que fazer

1. Abra a tela de consulta de cliente.
2. Consulte o cliente de código `000001`.
3. Leia a tela e anote nome, CPF, cidade e UF desse cliente.
4. Na mesma tela, consulte o cliente de código `000999`.
5. Leia a mensagem que o sistema mostrou.
6. Volte ao menu principal. **O caso termina no menu.**

Não inclua nem altere nenhum cliente.

## O que declarar

Em `claims` do `evidence/<run_id>/agent-result.json`, com `"case": "C4"`:

| Chave | Tipo | Formato |
|---|---|---|
| `nome` | texto | Nome do cliente `000001`, como na tela, sem espaços no fim |
| `cpf` | texto | CPF do cliente `000001`: 11 dígitos, entre aspas |
| `cidade` | texto | Cidade do cliente `000001`, como na tela, sem espaços no fim |
| `uf` | texto | UF do cliente `000001`: 2 letras |
| `mensagem` | texto | O texto da linha 24 depois da consulta de `000999`, exatamente como na tela |

Formato (valores fictícios):

```json
"claims": { "nome": "FULANO DE TAL", "cpf": "00000000000", "cidade": "CIDADE", "uf": "XX", "mensagem": "TEXTO DA LINHA 24" }
```
